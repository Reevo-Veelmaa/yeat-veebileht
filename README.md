# Yeat – artisti tutvustus

Veebileht tutvustab Yeati muusikat ja albumeid. Valminud HTML-i ja CSS-i seminari tööna.

## Avamine

Laadi failid alla ja ava `index.html` brauseris.

## Failid

- `index.html` – artisti tutvustus ja albumite tabel
- `muusika.html` – lähemalt Yeati muusikast
- `style.css` – lehe kujundus ja kohanduv paigutus
- `yeat.png` – artisti foto

Suurel ekraanil on sisu kahes tulbas, telefonis ühes. Nuppudel on CSS-iga loodud liikumisefekt.
